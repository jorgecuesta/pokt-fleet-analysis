# Visual assets

Fleet Observatory uses an original geometric network mark in `fleet-mark.svg`.
It is an independent research prototype, not an official network product.

Rubik is a variable Latin WOFF2 font. The bundled file is unmodified:
https://fonts.gstatic.com/s/rubik/v31/iJWKBXyIfDnIV7nBrXyw023e.woff2.
Copyright 2015 The Rubik Project Authors. It is distributed under the
SIL Open Font License 1.1, included in RUBIK-OFL.txt and in the built HTML.

The mark and font are embedded at build time. Opening the preview does not
request fonts, images, analytics, or live data from external services.
