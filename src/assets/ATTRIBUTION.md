# Visual reference assets

The Pocket white wordmark is the unmodified public asset at
https://pocket.network/wp-content/uploads/2025/01/logo-white.png.
The visual reference is Pocket Network's current official website,
https://pocket.network/, and its brand introduction,
https://pocket.network/a-new-look-for-a-new-era/.
This fictional product preview does not assert an official affiliation.

Rubik is the variable Latin WOFF2 font served by the official site's
Google Fonts stylesheet. The bundled file is unmodified:
https://fonts.gstatic.com/s/rubik/v31/iJWKBXyIfDnIV7nBrXyw023e.woff2.
Copyright 2015 The Rubik Project Authors. It is distributed under the
SIL Open Font License 1.1, included in RUBIK-OFL.txt and in the built HTML.

Both assets are embedded at build time. Opening the preview does not
request fonts, images, analytics, or live data from external services.
